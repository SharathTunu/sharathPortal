# MLOps

## Deployment & Infrastructure at Scale

- Developed a **native automated deployment and management service** capable of maintaining, upgrading, and rolling back pipelines and services on remote servers at scale — used to manage software across **400+ remote servers** across US and EU regions.
- Built a **native remote terminal access service** using Ansible and Flask, enabling support teams to perform manual service tasks on all remote servers across regions without direct access.
- Deployed AI platforms in real-time production environments, maintaining continuous uptime across client sites.

## Microservices & Containerization

- Led the conversion of an entire ML platform into a **microservices architecture**, creating Docker images for every individual service.
- Managed Docker-based deployments, including maintaining images on **Docker Hub**.
- Worked with **Docker, Celery, and Jenkins** for CI/CD and background task management in production web environments.
- Deployed web applications on **AWS servers** using containerized services.

## GPU Resource Management

- Developed a **GPU availability manager** for the ML platform to schedule and route algorithm processing based on live GPU capacity.

## Ground Truth & QA Tooling

- Built a **Ground Truth QA tool** to assist QA teams in performing ground truth analysis on algorithms deployed in production across multiple client sites.

## ML Platform Maintenance

- Responsible for ongoing maintenance and bug resolution across AI engines and production codebases.
- Managed version control, code reviews, and release documentation including **design docs, release notes, and READMEs**.
- Integrated **etcd** for distributed configuration management and **RabbitMQ** for message brokering within the ML platform.

## REST API & Data Sync

- Developed **REST APIs and REST clients** to communicate with databases and sync state changes to production servers.
- Set up REST API frameworks using Django for backend data management.

## Tech Stack

- **Docker, Docker Hub, Ansible, Flask, Jenkins, Celery, AWS**.
- **RabbitMQ, etcd, nginx, Unix/Linux (Ubuntu, RHEL)**.
- **Shell scripting, Git, REST, SQL, PostgreSQL**.
- **Python, C++** for platform and infrastructure tooling.
